# 🎨 Визуальный гайд админ-интерфейса

## 📐 Компоненты и их использование

### 1️⃣ AdminPanel - Основная панель

```
┌─────────────────────────────────────────────────┐
│ 🔵 Заголовок панели                            │
├─────────────────────────────────────────────────┤
│ Основное содержимое панели                      │
│ Может быть текст, список, форма или что угодно │
│                                                  │
└─────────────────────────────────────────────────┘
```

**Параметры:**
- `title` - текст заголовка
- `icon` - иконка слева от заголовка
- `children` - виджеты внутри панели
- `padding` - отступы содержимого
- `backgroundColor` - фон панели
- `showDivider` - показать разделитель под заголовком

**Пример:**
```dart
AdminPanel(
  title: 'Информация',
  icon: Icons.info_rounded,
  children: [
    Text('Содержимое'),
  ],
)
```

---

### 2️⃣ MetricCard - Карточка метрики

```
┌────────────────┐
│ [🔵]           │  ← Иконка
│                │
│ 150            │  ← Значение (жирный, большой)
│ Пользователей │  ← Название
│ активных сейчас│  ← Подпись (опционально)
└────────────────┘
```

**Параметры:**
- `title` - название метрики
- `value` - главное число/значение
- `subtitle` - дополнительный текст
- `icon` - иконка метрики
- `gradient` - список из 2-3 цветов
- `onTap` - действие при клике

**Пример:**
```dart
MetricCard(
  title: 'Активные аккаунты',
  value: '42',
  subtitle: 'зарегистрировано',
  icon: Icons.people_rounded,
  gradient: [Color(0xFF10B981), Color(0xFF059669)],
)
```

---

### 3️⃣ AdminGridPanel - Сетка карточек

```
Автоматически распределяет элементы в N столбцов:

┌─────────┬─────────┬─────────┬─────────┐
│ Метрика │ Метрика │ Метрика │ Метрика │
├─────────┼─────────┼─────────┼─────────┤
│ Метрика │ Метрика │ Метрика │ Метрика │
└─────────┴─────────┴─────────┴─────────┘
```

**Параметры:**
- `title` - заголовок сетки
- `icon` - иконка заголовка
- `items` - список компонентов
- `columnCount` - количество колонн (по умолчанию 2)
- `spacing` - расстояние между элементами

---

### 4️⃣ AdminListPanel - Панель со списком

```
┌─ Название панели ────────────────────┐
├──────────────────────────────────────┤
│ 👤 Элемент 1                         │
│    Дополнительная информация         │
├──────────────────────────────────────┤
│ 👤 Элемент 2                         │
│    Дополнительная информация         │
├──────────────────────────────────────┤
│ 👤 Элемент 3                         │
│    Дополнительная информация         │
├──────────────────────────────────────┤
│          [→ Показать всё]            │
└──────────────────────────────────────┘
```

**Параметры:**
- `title` - заголовок панели
- `items` - список AdminListItem
- `onViewAll` - действие для кнопки "Показать всё"
- `icon` - иконка

**Элемент списка (AdminListItem):**
```dart
AdminListItem(
  title: 'Иван Петров',
  subtitle: 'Учитель • Класс 10А',
  leading: CircleAvatar(child: Text('И')),
  trailing: Icon(Icons.arrow_forward_rounded),
)
```

---

### 5️⃣ AdminActionButton - Кнопка действия

```
┌────────────────────────┐  Первичная (синяя)
│ ✓ Создать аккаунт      │
└────────────────────────┘

┌────────────────────────┐  Обычная (серая)
│ 📁 Загрузить файл      │
└────────────────────────┘

┌────────────────────────┐  Опасная (красная)
│ 🗑️  Удалить           │
└────────────────────────┘
```

**Параметры:**
- `label` - текст кнопки
- `icon` - иконка
- `onPressed` - действие при нажатии
- `isPrimary` - основная кнопка (синяя)
- `isDangerous` - опасная кнопка (красная)

**Пример:**
```dart
AdminActionButton(
  label: 'Создать',
  icon: Icons.add_rounded,
  isPrimary: true,
  onPressed: () => print('Создание'),
)
```

## 💡 Правила дизайна

### 1️⃣ Иерархия
- **Заголовок** - 24px, w700
- **Подзаголовок** - 18px, w700
- **Текст** - 14px, w500
- **Мелкий текст** - 12px, w400

### 2️⃣ Белое пространство
- Минимум отступа: 8px
- Между элементами: 12-16px
- Между панелями: 20-24px
- Внутри панели: 16-20px

### 3️⃣ Иконки
- Всегда рядом с текстом
- Одинаковый размер на уровне
- Одна иконка = одно действие

### 4️⃣ Кнопки
- Первичная - заметная, часто используется
- Вторичная - менее важное действие
- Опасная - красная, для удаления/отклонения

### 5️⃣ Цвета по ролям
- 👨‍🏫 **Учителя** - Зелёный (#10B981)
- 👨‍🎓 **Ученики** - Синий (#3B82F6)
- 👨‍👩 **Родители** - Жёлтый (#F59E0B)
- 👮 **Администраторы** - Фиолетовый (#A855F7)
